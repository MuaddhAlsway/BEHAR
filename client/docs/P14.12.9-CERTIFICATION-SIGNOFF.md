## D. Defects discovered and fixed

### Student certificate flow had no Arabic language control

- Severity: Medium
- Reproduction: Open `/student/certificates`; the student layout did not expose the public footer language switch.
- Root cause: The existing switch lived in `Footer.jsx`, which is not rendered in the student dashboard layout.
- Fix: Added one accessible switch to the Certificates page using the same document attributes and localStorage key as the existing global switch.
- Retest: Arabic dashboard, preview, PDF download, and rendered PDF all passed.
